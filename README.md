
# Library Management System

A console-based Library Management System developed using Java.
It helps manage books and track their issue and return status.

## Features

- Add new books
- View all available and issued books
- Search books using their ID
- Issue books
- Return issued books
- Automatically assign book IDs
- Prevent issuing an already-issued book

## Technologies Used

- Java
- ArrayList
- Object-Oriented Programming
- Scanner for user input

## How to Run

### Prerequisites
Install Java JDK on your system.

### Compile the Program

```bash
javac LibraryManagementSystem.java
```

### Run the Program

```bash
java LibraryManagementSystem
```
